# Компьютерная помощь — Landing Page

Современный одностраничный сайт для сервиса ремонта компьютеров, ноутбуков и моноблоков.

## Описание

Полноценный landing page с тёмной минималистичной дизайн-системой, glassmorphism-эффектами, плавными анимациями и полной адаптивностью. Сайт готов к публикации на любом статическом хостинге.

## Структура проекта

```
computer-help/
├── index.html      # Основная разметка (семантический HTML5)
├── style.css       # Стили (CSS3, без Bootstrap)
├── script.js       # Интерактивность
├── robots.txt      # Правила для поисковых роботов
├── sitemap.xml     # Карта сайта
└── README.md       # Документация
```

## Возможности

- **Hero-блок** с анимированными счётчиками и CTA
- **Преимущества** — 6 карточек
- **Услуги** — 12 карточек с иконками и ценами «от»
- **Почему выбирают нас** — статистика и доверие
- **Этапы работы** — вертикальная временная шкала
- **Отзывы** — 6 карточек с рейтингом
- **FAQ** — аккордеон
- **Форма заявки** — валидация, маска телефона, модальное окно успеха
- **Контакты** — телефон, Telegram, WhatsApp, email, адрес, карта, график
- **Footer** с навигацией и политикой конфиденциальности

## Технические особенности

| Функция | Реализация |
|---------|------------|
| Липкое меню | Fixed header + класс `.scrolled` |
| Мобильное меню | Burger + выпадающая навигация |
| Анимации при скролле | Intersection Observer |
| Счётчики | requestAnimationFrame + easing |
| FAQ Accordion | Чистый JS |
| Маска телефона | `+7 (___) ___-__-__` |
| Валидация формы | Имя + телефон |
| Кнопка «Наверх» | Появляется после 500px скролла |
| Плавный скролл | CSS `scroll-behavior` + JS offset |
| SEO | Title, Description, Open Graph, Schema.org, robots.txt, sitemap.xml |
| Адаптив | Mobile-first, breakpoints 1100 / 960 / 640 / 400 |
| Шрифты | Google Fonts: Inter + Space Grotesk |
| Иконки | Inline SVG |

## Как опубликовать

1. Загрузите все файлы в корень сайта или в папку на хостинге (Netlify, Vercel, GitHub Pages, обычный хостинг).
2. Замените в `index.html` и `sitemap.xml` домен `computer-help.example.com` на ваш реальный.
3. Обновите телефон, Telegram, WhatsApp, email и адрес в `index.html`.
4. Подключите форму к бэкенду / Telegram-боту / сервису заявок (сейчас форма логирует данные в консоль и показывает модальное окно).
5. При необходимости добавьте `og-image.jpg` и обновите путь в мета-тегах.

## Настройка формы (пример)

В `script.js` в обработчике `submit` замените блок с `console.log` на отправку данных, например:

```js
fetch('https://your-api.example.com/order', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(formData),
})
.then(() => openModal())
.catch(() => alert('Ошибка отправки. Позвоните нам.'));
```

## Браузерная поддержка

Современные браузеры: Chrome, Firefox, Safari, Edge (последние 2 версии). Используются `backdrop-filter`, CSS Grid, Intersection Observer, `requestAnimationFrame`.
